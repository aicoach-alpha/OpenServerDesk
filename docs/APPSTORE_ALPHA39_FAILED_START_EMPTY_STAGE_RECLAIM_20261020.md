# OpenServerDesk Alpha 0.7.0-alpha.39 — post-rollback empty staging reclaim

## Delivered
- After a stage application fails during startup, rollback first verifies
  the exact stage-owned Docker container IDs, project network and registry
  status. The protected Qui delayed-ready path is unchanged.
- Once rollback succeeds and its install recovery journal is safely removed,
  the existing strict empty-scaffold validator may clean the generated
  preparation directory as a best-effort final step.
- The validator rejects files not generated by OpenServerDesk, symbolic
  links, mounted filesystem entries, foreign Docker containers/networks,
  recovery markers, and any non-empty stage-owned data volume.
- A refused cleanup does not mask the original startup error. Non-empty
  stage volumes and user-provided data remain untouched and reviewable.
- The cleanup has no recursive deletion and never traverses CasaOS
  production paths or Nextcloud user data on the external HDD.
- Two narrowly targeted temp-fixture tests PASS: a completely empty
  compensated stage leaves no orphan directory; retained stage data
  remains intact. No repeated real Docker startup test.
- The two earlier Glances UAT attempts failed on (1) a startup grace
  mismatch, subsequently fixed in Alpha .38, and (2) app process exiting
  early. Both test projects rolled back, with the original two registered
  stage projects restored. Glances functional runtime parity is unproven.
- The two prior failed trials left historical unregistered stage folders;
  these are intentionally NOT automatically deleted by this release.
  Manual per-project read-only eligibility preview and opt-in empty cleanup
  are available from the .35/.36 housekeeping interface.

## Platform integrity boundaries
- Alpha .39 does not approve production cutover.
- Synthetic Docker broker has no write access to host Docker through the
  untrusted application container.
- 675/726 CasaOS App Store definitions have static safe stage plans;
  this is not evidence of 675 functioning applications.
